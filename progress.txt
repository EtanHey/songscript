## 🔒 SECURITY FIX: Auth Overhaul (SEC-001 through SEC-012)

**CRITICAL CONTEXT FOR ALL SEC STORIES:**

### The Problem
- ALL user data queries accept `visitorId` as argument (SPOOFABLE!)
- `visitorId` comes from localStorage (browser-specific, not user-specific)
- Two users on same browser share the same visitorId = SHARED DATA BUG

### The Solution
- Use `ctx.auth.getUserIdentity()` server-side (cryptographically verified, CANNOT be spoofed)
- NEVER accept user ID as function argument
- Add userId field to all tables, query by userId using ctx.auth

### Key Pattern
```typescript
// ❌ WRONG (spoofable)
export const getData = query({
  args: { visitorId: v.string() },
  handler: async (ctx, { visitorId }) => { ... }
});

// ✅ CORRECT (secure)
import { requireAuth } from './authHelpers';
export const getData = query({
  args: {},
  handler: async (ctx) => {
    const userId = await requireAuth(ctx);  // From ctx.auth
    return ctx.db.query('data').withIndex('by_user', q => q.eq('userId', userId)).collect();
  }
});
```

### Migration Flow
1. User visits /signup with anonymous progress in localStorage
2. Enters email, display name, checks "Bring my progress" (default ON)
3. Magic link sent → clicks link → /auth/verify
4. verify.tsx: calls migrateAnonymousData(), sets displayName, clears localStorage
5. User now has all their progress tied to their authenticated account

## Learnings
(Mark with [DONE] when promoted to CLAUDE.md)

- NO INLINE COLORS: Use Tailwind preset tokens (primary-50, etc.), never arbitrary hex
- NO ARBITRARY PIXELS: Use Tailwind scale (gap-4, py-12) or @theme CSS variables
- RTL: Inner flex containers need explicit dir="rtl" - doesn't propagate automatically
- WORD SYNC: Use persian text as primary key, not wordId - words are unique tokens
- LOOP MODE: Guard against line-change events during seek to prevent flashing
- Convex bundler error "Two output files share same path" = delete .js files from convex/
- Convex env vars: Cloud functions need keys configured in dashboard.convex.dev, not .env.local
- TanStack Start SSR: use createServerFn + ConvexHttpClient in loader, pass to useQuery via initialData
- Browser autoplay: video must be muted, attempt on canplay event, provide fallback "Click to play" button
- Playwright webServer config: essential for CI - auto-start dev server before e2e tests
- ElevenLabs: returns 401 with quota_exceeded when out of credits

## Learning: Delete User for Testing Signup Flow

When testing signup/login flows and need to reuse an email:

1. Open Convex Dashboard: `npx convex dashboard`
2. Go to "Data" tab
3. Find `users` table
4. Delete the user row with the email you want to reuse
5. Also check `user` table (Better Auth's table) and delete there too

Or via Convex CLI:
```bash
# List users
npx convex run --query "db.query('users').collect()"

# Delete specific user (get _id from above)
npx convex run --mutation "db.delete(args.id)" --args '{"id": "USER_ID_HERE"}'
```

This allows re-testing the full signup flow with the same email.
