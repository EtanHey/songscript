## Learnings

- NO ARBITRARY PIXELS: Use Tailwind scale (gap-4, py-12) or @theme CSS variables
- RTL: Inner flex containers need explicit dir="rtl" - doesn't propagate automatically

## Iteration - US-LOOP-UX: Fix Loop Mode Line Flashing ✅
- Identified the source of the flash: handleTimeUpdate was updating activeLineIndex during seek operations
- Root cause: When video seeks back to loop start, timeupdate events fire with intermediate positions
- Fix: Added `isLoopSeekingRef` to track when we're in a loop restart seek operation
- Guard added in handleTimeUpdate to skip line updates when isLoopSeekingRef.current is true
- Loop restart now sets flag before seek, clears after 50ms timeout
- Typecheck passes
- **Learning:** Use a ref flag to guard against state updates during async seek operations - prevents visual flicker by "locking" UI state during transitions
