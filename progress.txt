## Iteration - Fix dashboard word count inconsistencies and wrong direction
- Fixed critical bug where Daily Goals and Your Stats showed different word counts due to inconsistent calculation logic
- Root cause: Daily Goals counted ANY word interaction (viewing/clicking) while Your Stats only counted explicitly learned words
- Solution: Updated goals.ts to only count words marked as learned (wp.learned === true), matching userStats.ts logic
- Fixed word unmarking bug where unmarking words caused count to go UP instead of down
- Root cause: toggleLearned mutation updated lastSeen timestamp even when unmarking, causing unmarked words to be counted as "practiced today"
- Solution: Modified toggleLearned and setLearned mutations to only update lastSeen when marking as learned, not when unmarking
- Investigated wordProgress vs practiceLog discrepancy - confirmed these are separate systems (word learning vs practice sessions) with no actual conflict
- All word count calculations now consistent: marking increases count by 1, unmarking decreases by 1, count cannot exceed actual marked words
- Typecheck passes - no TypeScript errors
- Learnings: When tracking user progress, ensure consistent calculation logic across all UI components that display the same metric

## Learnings
(Mark with [DONE] when promoted to CLAUDE.md)

- NO INLINE COLORS: Use Tailwind preset tokens (primary-50, etc.), never arbitrary hex
- NO ARBITRARY PIXELS: Use Tailwind scale (gap-4, py-12) or @theme CSS variables
- RTL: Inner flex containers need explicit dir="rtl" - doesn't propagate automatically
- WORD SYNC: Use persian text as primary key, not wordId - words are unique tokens
- LOOP MODE: Guard against line-change events during seek to prevent flashing
- Convex bundler error "Two output files share same path" = delete .js files from convex/
- Convex env vars: Cloud functions need keys configured in dashboard.convex.dev, not .env.local
- TanStack Start SSR: use createServerFn + ConvexHttpClient in loader, pass to useQuery via initialData
- Browser autoplay: video must be muted, attempt on canplay event, provide fallback "Click to play" button
- Playwright webServer config: essential for CI - auto-start dev server before e2e tests
- ElevenLabs: returns 401 with quota_exceeded when out of credits
