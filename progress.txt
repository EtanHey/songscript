## Learnings
(Mark with [DONE] when promoted to CLAUDE.md)

- NO INLINE COLORS: Use Tailwind preset tokens (primary-50, etc.), never arbitrary hex
- NO ARBITRARY PIXELS: Use Tailwind scale (gap-4, py-12) or @theme CSS variables
- RTL: Inner flex containers need explicit dir="rtl" - doesn't propagate automatically
- WORD SYNC: Use persian text as primary key, not wordId - words are unique tokens
- LOOP MODE: Guard against line-change events during seek to prevent flashing

- Created e2e/routes.spec.ts with tests for /, /login, and /song/{songId}
- All 39 unit tests pass, all 6 e2e tests pass, typecheck passes
- **Learning:** TanStack Start requires both shellComponent (for HTML shell) AND component (with <Outlet />) for child routes to render properly with code splitting
