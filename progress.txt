# Progress Log

## Learnings
(Mark with [DONE] when promoted to CLAUDE.md)

- NO INLINE COLORS: Use Tailwind preset tokens (primary-50, etc.), never arbitrary hex like bg-[#E9EFFD]
- NO ARBITRARY PIXELS: Use Tailwind scale (gap-4, py-12) or @theme CSS variables
- RTL: Persian and Hebrew text must have dir="rtl" and text-right
- TanStack Start + Bun: Use `bun --bun` prefix for scripts, `nitro({ preset: "bun" })` in vite config
- Convex + TanStack Start: Use @convex-dev/react-query for SSR + live updates

- Convex Better Auth: Use `@convex-dev/better-auth` with `better-auth@1.4.9` pinned
- Convex Components: File naming matters - avoid naming files `auth.ts` in convex/ folder when using betterAuth component (causes bundler conflicts)
- Convex dev won't work with stray .js files in convex/ folder - remove them if build fails with "Two output files share the same path"
